# Implementation Plan: Allauth Password Change Templates

**Branch**: `007-allauth-password-change` | **Date**: 2026-05-12 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/007-allauth-password-change/spec.md`

## Summary

Rewrite four existing template overrides in `dac/addons/allauth/templates/account/`
so that the password-change and reauthentication flows render correctly inside the
DAC layout using Cotton components. All four templates currently use allauth
`{% element %}` / `{% endelement %}` tags; two of them (`password_change.html`,
`password_set.html`) also use `{% block content %}` instead of
`{% block page.content %}`, meaning their forms never render inside the DAC
card-stack.

**Four template changes** (in dependency order):

1. `account/base_reauthenticate.html` — replace all `{% element %}` tags with Cotton
   equivalents; keep `{% block reauthenticate_content %}` extension hook
2. `account/reauthenticate.html` — fill `{% block reauthenticate_content %}` with
   Cotton form components (`<c-form>`, `<c-button>`)
3. `account/password_change.html` — full rewrite: `{% block page.content %}` +
   `<c-form.card>` + breadcrumb + `{% trans %}` strings
4. `account/password_set.html` — same structure as `password_change.html` but for
   the set-password flow (no "Forgot Password?" link)

Integration tests are written during implementation in
`tests/test_addons/test_allauth/test_password_change_view.py`. Playwright screenshot
tests are written in `screenshots/test_password_change_screenshots.py`.

## Phase 1: Design & Contracts

### Template Block Contract (data-model.md)

Management templates (`password_change.html`, `password_set.html`) inherit through
`base_manage_password.html → base_manage.html → dac/base.html` and consume:

| Block | Purpose | Default |
|---|---|---|
| `title` | Toolbar page title | (empty) |
| `page.breadcrumbs` | Breadcrumb items appended after "Account Center" root | (root only) |
| `page.content` | Main content area inside `card.stack` | "Coming soon…" |

Entrance templates (`base_reauthenticate.html`, `reauthenticate.html`) inherit through
`base_entrance.html → allauth/layouts/entrance.html` and use:

| Block | Purpose |
|---|---|
| `content` | Main content of the entrance page (heading, intro, form, alternatives) |
| `reauthenticate_content` | Extension hook for child templates to inject their form |

### Component Interface (contracts/component-interface.md)

**`base_reauthenticate.html`** — rewritten structure:

```
{% extends "account/base_entrance.html" %}
{% load i18n %}

{% block title %}{% trans "Confirm Access" %}{% endblock %}

{% block content %}
  <c-entrance.section text="{% trans "Please reauthenticate to safeguard your account." %}">
    {% block reauthenticate_content %}{% endblock %}
  </c-entrance.section>
  {% if reauthentication_alternatives %}
    <c-card.divider text="{% trans "Alternative options" %}" />
    <c-button.stack>
      {% for alt in reauthentication_alternatives %}
        <c-button href="{{ alt.url }}" variant="outline-primary" text="{{ alt.description }}" />
      {% endfor %}
    </c-button.stack>
  {% endif %}
{% endblock %}
```

**`reauthenticate.html`** — rewritten structure:

```
{% extends "account/base_reauthenticate.html" %}
{% load i18n %}

{% block reauthenticate_content %}
  <c-form method="post" action="{% url 'account_reauthenticate' %}" :form-obj="form">
    {{ redirect_field }}
    <c-button.stack>
      <c-button type="submit" variant="primary" text="{% trans "Confirm" %}" />
    </c-button.stack>
  </c-form>
{% endblock %}
```

**`password_change.html`** — rewritten structure:

```
{% extends "account/base_manage_password.html" %}
{% load i18n %}

{% block title %}{% trans "Change Password" %}{% endblock %}

{% block page.breadcrumbs %}
  {{ block.super }}
  <c-breadcrumbs.item text="{% trans "Change Password" %}" />
{% endblock %}

{% block page.content %}
  <c-form.card method="post"
               action="{% url 'account_change_password' %}"
               :form-obj="form">
    {{ redirect_field }}
    <c-slot name="actions">
      <c-button.stack>
        <c-button type="submit" variant="primary" text="{% trans "Change Password" %}" />
        <a href="{% url 'account_reset_password' %}">{% trans "Forgot Password?" %}</a>
      </c-button.stack>
    </c-slot>
  </c-form.card>
{% endblock %}
```

**`password_set.html`** — rewritten structure (no "Forgot Password?" link):
