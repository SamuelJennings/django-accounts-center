# Implementation Plan: User Sessions Management Templates

**Branch**: `010-usersessions-templates` | **Date**: 2026-05-22 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/010-usersessions-templates/spec.md`

## Summary

Correct two existing template overrides in `dac/addons/allauth/templates/usersessions/`
so that the user sessions management flow renders inside the DAC management layout.
The core defect mirrors specs 006/007/009: `usersessions/base_manage.html` extends
`allauth/layouts/manage.html` instead of `dac/base.html`, meaning the "Sessions"
page has never rendered inside the Account Center sidebar/breadcrumb/card-stack shell.
`usersession_list.html` compounds the problem by using `{% block content %}` and
allauth `{% element %}` tags throughout.

**Two template changes** (in dependency order):

1. `usersessions/base_manage.html` — change one `extends` line to `dac/base.html` (unblocks `usersession_list.html`)
2. `usersessions/usersession_list.html` — full rewrite: `{% block page.content %}`, Bootstrap `<table>` inside `<c-card>`, `<c-badge variant="success">` for the current session row, bulk sign-out form with `<c-button variant="primary">` (no per-session selection)

Integration tests and Playwright screenshot tests are **written as part of this
feature** in `tests/test_addons/test_allauth/test_usersessions_view.py` and
`screenshots/test_usersessions_screenshots.py`.
