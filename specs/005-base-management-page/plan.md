# Implementation Plan: Base Management Page

**Input**: Feature specification from `specs/005-base-management-page/spec.md`

## Summary

`dac/base.html` is the shared base template for all authenticated management pages in
`django-accounts-center`. The template is **already implemented** — it extends `base.html`,
injects the Account Center Menu into `app.sidebar`, wraps content in a `layouts.form-view`,
exposes a `title` block in a toolbar, and places all page content inside a `card.stack`.

The scope of this spec is exclusively **verification**: writing Cotton rendering tests
(`tests/test_components/`) that confirm every block, slot, and component composition
works correctly in isolation and as a unit.
No new template files, views, forms, models, or settings are introduced.

**Structure Decision**: Tests under `tests/test_components/` use the `cotton_render_string_soup`
fixture from `django-cotton-bs5` per Principle I.

**Deviation from plan**: A local `conftest.py` was required in `tests/test_components/`
to override `cotton_render_string_soup`. The upstream fixture's `RequestFactory` request
lacks `request.site` (set normally by `CurrentSiteMiddleware`), but templates in the
rendering chain (`mvp/base.html`, `app.header.html`, `app.sidebar.header.html`) access
`{{ request.site.name }}`. The override attaches `request.site = SimpleNamespace(name="Test
Site", domain="example.com", id=1)` so renders succeed without a database hit or middleware.

The `cotton-test-components` skill governs test fixture selection.

**Resolved decisions**:

| Decision | Rationale |
|---|---|
| Use `cotton_render_soup` for rendering tests | Template uses nested Cotton components; BeautifulSoup DOM assertions are more reliable than string matching |
| Test `dac/base.html` via a minimal stub sub-page | `dac/base.html` uses `{% block %}` tags; testing requires a concrete child template — use a minimal inline string passed to `cotton_render_string_soup` |

## Phase 1: Design & Contracts

### Component Interface Contract

The public block interface of `dac/base.html` for downstream sub-page authors:

| Block name | Default content | Override guidance |
|---|---|---|
| `app.sidebar` | `<c-app.sidebar menu="Account Center Menu" />` | Override to inject a different menu; rarely needed |
| `content` | Full management page structure | Override only to replace the entire layout |
| `breadcrumbs` | Toolbar + breadcrumbs wrapper | Override to change header structure; use `{{ block.super }}` to extend |
| `page.breadcrumbs` | Single item: "Account Center" → `account-center` URL | Always use `{{ block.super }}` then append additional items |
| `page.content-wrapper` | `<c-page.content class="container">` + `layouts.form-view` | Override only for full-width or non-form layouts |
| `title` | *(empty)* | Override with the page heading string; no wrapper needed |
| `page.content` | `{% trans "Coming soon..." %}` | Override with the page's primary UI content |

**Usage example** (minimal sub-page):

```django
{% extends "dac/base.html" %}
{% load i18n %}

{% block title %}{% trans "Change Password" %}{% endblock title %}

{% block page.breadcrumbs %}
  {{ block.super }}
  <c-navigation.breadcrumbs.item text="{% trans "Change Password" %}" />
{% endblock page.breadcrumbs %}

{% block page.content %}
  {# form content here #}
{% endblock page.content %}
```

## Test Design

### Cotton Rendering Tests (`tests/test_components/test_dac_base.py`)

Each test renders a minimal child template that extends `dac/base.html` via
`cotton_render_string_soup`, then asserts specific DOM properties.

| Test | What is asserted |
|---|---|
| `test_sidebar_injects_account_center_menu` | Rendered HTML contains an `<aside class="app-sidebar">` element, confirming the sidebar Cotton component was injected |
| `test_breadcrumbs_root_item_present` | Breadcrumb component renders an item with "Account Center" text linking to the account-center URL |
| `test_title_block_empty_by_default` | Toolbar title area renders empty when `title` block is not overridden |
| `test_title_block_override_renders` | Overriding `title` with "My Page" produces "My Page" in the toolbar title area |
| `test_page_content_placeholder_default` | `page.content` default renders the "Coming soon…" translation string |
| `test_page_content_block_override_renders` | Overriding `page.content` renders the provided content inside the card stack |
| `test_breadcrumbs_block_override_extends` | Overriding `page.breadcrumbs` with `{{ block.super }}` + a new item produces both "Account Center" and the new item |
